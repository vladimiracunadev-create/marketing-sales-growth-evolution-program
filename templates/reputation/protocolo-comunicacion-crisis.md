# Plantilla — Protocolo de comunicación de crisis

Debe estar aprobado por dirección y Legal **antes** de que sea necesario. Se prueba con al menos un [escenario](../../curriculum/specializations/reputacion-relaciones-publicas-y-crisis/README.md) al año.

## 1. Fases

Prevención → detección → contención → respuesta → corrección → recuperación → aprendizaje. Cada fase tiene dueño e indicador.

## 2. Niveles de severidad

| Nivel | Criterios observables | Responsable | Primera comunicación | Escala a |
|---|---|---|---|---|
| 1 · Incidente | sin afectados con perjuicio verificable ni interés público | | 24 h si corresponde | |
| 2 · Crisis | afectados con perjuicio verificable o conversación pública acelerada | | 2 h | |
| 3 · Crisis mayor | daño a seguridad, datos, salud o continuidad; interés de autoridades o medios | | 1 h | |

## 3. Equipo y roles

Dirección, comunicaciones, jurídico, operación afectada, atención al cliente, personas y seguridad. Cada rol tiene suplente y teléfono verificado.

## 4. Primeras tres horas

1. Verificar la señal con una fuente interna.
2. Clasificar el nivel.
3. Contener: proteger a afectados, detener lo que agrava, preservar evidencia.
4. Aplicar la **prueba de publicación completa** a cada texto.
5. Decidir y registrar: responder, reconocer, disculparse, corregir, suspender, escalar.
6. Fijar la hora de la próxima actualización.

## 5. Seis decisiones

| Decisión | Cuándo corresponde | Condición | Decide |
|---|---|---|---|
| Responder | hay afectados y fuente verificable | se puede decir qué se hace | |
| Reconocer un error | la evidencia interna lo confirma | hechos claros | |
| Pedir disculpas | la organización causó el daño | acción asociada | |
| Corregir | circula información falsa que afecta decisiones | prueba que la refuta | |
| Suspender publicaciones | el calendario contradice la experiencia | falla activa | |
| Escalar | supera autoridad, conocimiento o riesgo jurídico | | |

## 6. Canales

Fuente única de verdad, comunicado, perfil fijado, aviso en producto, correo a afectados y canal privado para datos personales.

## 7. Cierre

La crisis se cierra con evidencia: afectados reparados, medida correctiva en operación e indicador sostenido. Revisión posterior en 15 días con cambios, responsable y fecha.
