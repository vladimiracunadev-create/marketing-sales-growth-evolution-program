# Uso comercial

Este repositorio separa software y contenido educativo. Que el código permita uso comercial no convierte al
contenido en material comercialmente reutilizable.

## Resumen

| Material | Licencia actual | Uso comercial |
|---|---|---|
| Código fuente, scripts, validadores, generadores y componentes del portal | [MIT](../LICENSE) | Permitido, conservando el aviso y la licencia MIT. |
| Contenido educativo original, plantillas, playbooks, ejercicios y metodología propia | [CC BY-NC-SA 4.0](../LICENSE-CONTENT.md) | No concedido por la licencia pública. |
| Obras, metodologías, normas y marcas externas | Régimen de cada titular | Debe evaluarse con la fuente o el titular correspondiente. |
| Versiones históricas publicadas bajo MIT | MIT que acompañaba esa revisión | Se conservan los permisos de esa revisión; ver [historia](LICENSING_HISTORY.md). |

Creative Commons define `NoComercial` en función de si el uso está dirigido principalmente a una ventaja
comercial o compensación monetaria. El contexto importa; cobrar, vender acceso, incorporar el material a un
servicio pagado o usarlo como producto de capacitación puede requerir autorización separada.

## Usos normalmente cubiertos por CC BY-NC-SA 4.0

Siempre que se cumplan atribución, indicación de cambios y CompartirIgual, la licencia pública contempla el
estudio personal, la enseñanza gratuita y la adaptación o distribución sin propósito principalmente
comercial. Las excepciones y limitaciones legales aplicables siguen existiendo independientemente de la
licencia.

## Usos que requieren evaluación o permiso

Solicita autorización antes de reutilizar el contenido actual en, por ejemplo:

- cursos, talleres, membresías o consultorías cobradas;
- capacitación corporativa prestada como servicio o integrada a una oferta comercial;
- libros, plataformas, LMS o paquetes de plantillas vendidos;
- campañas destinadas a promocionar o monetizar una adaptación sustancial del contenido.

La autorización sobre el contenido original no puede conceder derechos sobre metodologías, obras o marcas de
terceros. Esas exclusiones están en [`../THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

## Cómo solicitar autorización

Abre una consulta en el repositorio de GitHub de `vladimiracunadev-create` describiendo:

1. material y revisión exactos;
2. uso, audiencia, territorio y duración;
3. si existe cobro o ventaja comercial;
4. modificaciones y forma de atribución;
5. componentes externos que también se usarán.

No hay autorización hasta recibir una respuesta expresa del titular. Este documento explica la política del
repositorio; no es asesoría jurídica.
